## ⚙️ The Hidden Mechanism — Why a 6-Section UI Scaffold Beats a Basic Production Board
The basic production board format has 2 UI sections at the bottom: Music Journey + Camera Movement Guide. Those 2 sections direct rhythm and motion. Useful, but they don't direct the model's **rendering decisions**.
The 6-section pitch deck scaffold adds 4 more directional layers:
→ **Production Notes** — campaign-level rules the model should follow (e.g. "focus on texture and premium feel," "smooth transitions with motion blur")<br>→ **Restrictions** — explicit anti-instructions (e.g. "do NOT overexpose," "avoid shaky camera," "do NOT use distracting backgrounds")<br>→ **What Not To Do** — quality floor rules (e.g. "no low quality footage," "avoid cluttered compositions")<br>→ **Tone / Style icons** — 5 brand aesthetic locks (PREMIUM, BOLD, ENERGETIC, MODERN, TIMELESS) that the model treats as palette + composition guides
The model parses each section as a separate rule category. Restrictions get treated as hard "do not render" directives. Tone icons get treated as aesthetic anchors that pull the visual palette toward premium agency conventions. Production Notes get treated as campaign-wide style overrides.
Result: the rendered storyboard looks like it came out of a real creative agency pitch deck — because the prompt scaffolding mirrors how a real agency actually structures a campaign pitch.
The fix is not better visual prompts. The fix is **encoding agency-level rules as UI sections** that the model treats as production direction rather than scene content.

## ⚙️ What NOT to Do
→ Don't strip any of the 6 UI sections from the master prompt. The Pitch Deck tier IS the 6-section scaffold. Drop sections and you're back to basic production board.
→ Don't skip the ARRI ALEXA MINI LF + 85mm + macro spec scaffolding. The camera specs are what push Seedance toward agency-grade output instead of generic video model defaults.
→ Don't pick more than 5 tone icons. The 5-icon limit forces clarity. Stacking 8 icons confuses the model.
→ Don't write generic restrictions. "Avoid bad backgrounds" is generic. "Do NOT use distracting backgrounds" is directional. The verb specificity matters.
→ Don't pick contradictory tone icons. Athletic + Romantic + Premium creates aesthetic conflict. Pick 5 that cluster.
→ Don't run the pitch deck on cold-audience hook-rate tests. Hold rate + brand recall + retargeting is the strength. Use UGC + broadcast for cold-audience interruption.
→ Don't deploy without 3 aspect ratios. Export 16:9 for YouTube, 9:16 for Reels/TikTok, 1:1 for Meta feed.
→ Don't ignore reverse-direction Seedance panels. 1-2 panels per generation may render in reverse. Fix in CapCut (30 seconds per panel).
→ Don't deviate from the 15-panel structure on the first 10 generations. The 15-panel pitch deck arc is calibrated. Deviate only after 10 cycles of data.
→ Don't skip the brand identity scaffold (Step 1). Without 8 locked fields, generation defaults to generic pitch deck aesthetic.
→ Don't use this format for talking-head UGC. The pitch deck format is for cinematic product/brand storytelling without dialog.
