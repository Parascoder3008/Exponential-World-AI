## ⚙️ How the AI Creative Department Works

Each of the 50 agents lives as a saved Claude project or skill. You invoke by role name. You feed the required input (product brief, ad concept, competitor URL, whatever the agent needs). You get back the specific output that agent is responsible for.

The 5 teams:

→ **Team 1 — Ad Research Agents (10)**: what's working in your category right now
→ **Team 2 — Brand Positioning Agents (10)**: how you sound / look / feel different
→ **Team 3 — Creative Concept Agents (10)**: what to make + how to make it
→ **Team 4 — Production Strategy Agents (10)**: exact briefs for Seedance 2.0 execution
→ **Team 5 — Performance Analysis Agents (10)**: what's working after deploy + what to iterate

Every specialist has one responsibility. Together, they turn messy DTC creative into a repeatable operating system, from ad research and positioning to concept generation, Seedance-ready production briefs, and post-deploy analysis.

## 👥 Team 1 — Ad Research Agents (10)

Deep intelligence on what's working in your category right now.

### Agent 1.1 — Competitor Ad Auditor
**Role**: Pulls the top 20 Meta + TikTok ads from a competitor and identifies hook patterns, structure, and performance signals.
**Trigger**: When entering a new vertical or scaling a competitor's audience.
**Prompt**:
```javascript
Audit the top 20 Meta Ad Library + TikTok Creative Center ads for [COMPETITOR NAME] in [VERTICAL]. For each: hook line, format (UGC / cinematic / reaction / BTS vlog / carousel), duration, product moment placement, CTA style. Rank by estimated performance signal. Identify the top 3 patterns worth cloning.
```

### Agent 1.2 — Winning Hook Archaeologist
**Role**: Extracts the underlying hook mechanic from viral ads across categories.
**Trigger**: When your hook rate plateaus.
**Prompt**:
```javascript
Analyze these 10 ads that generated 1M+ views: [PASTE ADS]. Extract the underlying hook mechanic per ad (question / shock / contradiction / mystery / reveal / claim). Map each to a hook archetype. Output 5 hook archetypes I can adapt for [PRODUCT].
```

### Agent 1.3 — Category Trend Radar
**Role**: Tracks emerging creative trends in your vertical before they saturate.
**Trigger**: Weekly on Mondays.
**Prompt**:
```javascript
Scan Reddit r/[VERTICAL], TikTok #[VERTICAL] top posts this week, Meta Ad Library new entries in [VERTICAL]. Identify 5 emerging creative trends operators are testing but haven't fully saturated. Rank by opportunity size.
```

### Agent 1.4 — Angle Extraction Engine
**Role**: Pulls every buyer angle a competitor is running.
**Trigger**: Before running competitor audience acquisition.
**Prompt**:
```javascript
For [COMPETITOR], catalog every buyer angle their ads exploit (price / quality / mechanism / social proof / founder story / regret prevention / status / speed / ease). Rank angles by frequency + inferred performance. Recommend 3 they're NOT running that we could own.
```

### Agent 1.5 — Format Frequency Mapper
**Role**: Identifies which ad formats a competitor over-invests in and which they under-invest in.
**Trigger**: Quarterly competitive review.
**Prompt**:
```javascript
Across [COMPETITOR]'s last 90 days of Meta + TikTok ads, quantify format mix: UGC talking-head, reaction UGC, cinematic, BTS vlog, product-only, carousel. Identify format gaps we can own.
```

### Agent 1.6 — Testimonial Pattern Scanner
**Role**: Extracts recurring language patterns from customer reviews across the category.
**Trigger**: When writing ad copy hooks.
**Prompt**:
```javascript
Scan 100+ 5-star + 1-star reviews for [COMPETITOR PRODUCT] on Amazon + brand site. Extract the top 15 recurring language patterns (both positive and negative). These become hook material for our ads.
```

### Agent 1.7 — Influencer Format Analyst
**Role**: Analyzes what formats top influencers in your niche are using.
**Trigger**: Before commissioning influencer campaigns.
**Prompt**:
```javascript
For [NICHE], identify top 10 influencers running paid promotions. Map their preferred content formats (UGC / reaction / GRWM / storytime / review). Recommend which format performs best per audience size tier.
```

### Agent 1.8 — Landing Page Reverse-Engineer
**Role**: Maps competitor landing pages to understand their claim + proof + CTA structure.
**Trigger**: When your ad-to-LP conversion drops.
**Prompt**:
```javascript
Audit [COMPETITOR] top 5 landing pages. Map: primary claim, proof stack, social proof placement, CTA structure, price presentation, guarantee language. Identify 3 elements we should test on our LP.
```

### Agent 1.9 — Ad Copy Corpus Builder
**Role**: Compiles the best-performing ad copy in your vertical into a reference library.
**Trigger**: When writing new hooks or scripts.
**Prompt**:
```javascript
Build a corpus of the top 30 highest-performing ad copies in [VERTICAL] from the last 60 days. Tag each by: hook type, angle, format, estimated funnel position. This becomes the input for creative concept generation.
```

### Agent 1.10 — Saturation Detector
**Role**: Identifies when a hook, format, or angle has been overused in the category.
**Trigger**: Before committing spend to a specific creative direction.
**Prompt**:
```javascript
For [HOOK / FORMAT / ANGLE], scan how many competitors are currently using it in [VERTICAL]. Rate saturation: fresh (0-2 competitors) / rising (3-5) / peak (6-10) / saturated (10+). Recommend adjacent variants if saturated.
```

How your brand sounds, looks, and feels different in every ad.

**Role**: Builds a full ICP profile with psychographic + demographic depth.
**Trigger**: Before every major campaign.
**Prompt**:
```javascript
For [BRAND], build the primary ICP profile: demographic (age, income, geography), psychographic (values, fears, aspirations), day-in-life narrative, purchase triggers, objection stack. Include the sub-ICPs (secondary + tertiary).

### Agent 2.3 — Positioning Statement Generator
**Role**: Writes single-line brand positioning statements you can test.
**Trigger**: When repositioning or launching new SKUs.
**Prompt**:
```javascript
For [BRAND + PRODUCT], generate 10 positioning statement variants using the format: "For [ICP] who [PAIN], [PRODUCT] is the [CATEGORY] that [MECHANISM] unlike [ALTERNATIVE] which [FAILURE MODE]." Rank by memorability + specificity.

### Agent 2.4 — Category Framing Architect
**Role**: Reframes your product into a new category to escape commodity comparison.
**Trigger**: When margin pressure from competitors is squeezing performance.
**Prompt**:
```javascript
For [BRAND + PRODUCT], invent 5 alternative category framings that reposition the product outside its default competitive set. Each framing: category name, ICP shift, price justification, ad angle implication.

**Role**: Identifies where your brand IS actually different from competitors.
**Trigger**: Quarterly brand review.
**Prompt**:
```javascript
Compare [BRAND] to top 5 competitors across: ingredients / features, price, brand aesthetic, voice, founder story, guarantee, community. Identify the 3 real points of differentiation. Discard the 5 fake ones you're using in ads.

### Agent 2.6 — Aesthetic Codex Builder
**Role**: Documents the visual language of your brand (colors, textures, mood, camera language).
**Trigger**: Before every new production run.
**Prompt**:
```javascript
For [BRAND], codify the visual aesthetic: 5-color palette, 3 texture references, mood adjectives, camera language, character archetype, setting archetype, lighting arc. This becomes the input to every Seedance production brief.

### Agent 2.7 — Story Spine Author
**Role**: Writes the founder / brand origin story in 3 lengths (30-sec, 90-sec, 5-min).
**Trigger**: Once. Then reuse across all ads + LP + PR.
**Prompt**:
```javascript
For [BRAND + FOUNDER], write the founder origin story in 3 versions: 30-second ad hook / 90-second BTS vlog script / 5-minute podcast talking points. Anchor each on a specific human moment, not corporate mission.

### Agent 2.8 — Value Prop Ladder Builder
**Role**: Structures your value props from surface to deep.
**Trigger**: When mapping campaign architecture.
**Prompt**:
```javascript
For [BRAND + PRODUCT], structure value props as a ladder: surface (visual promise) → functional (what it does) → emotional (how it makes them feel) → identity (who they become). Each layer becomes a different ad funnel position.

### Agent 2.9 — Objection Preemption Writer
**Role**: Writes the copy that kills objections before they form.
**Trigger**: When bottom-funnel conversion drops.
**Prompt**:
```javascript

### Agent 2.10 — Brand Register Enforcer
**Role**: Flags off-brand language in any copy before it ships.
**Trigger**: Every ad script + landing page before deploy.
**Prompt**:
```javascript

## 👥 Team 3 — Creative Concept Agents (10)

What to make. How to make it interesting.

### Agent 3.1 — Concept Generator
**Role**: Produces 20 ad concepts per product from a single brief.
**Trigger**: Monday morning ideation.
**Prompt**:
```javascript
For [PRODUCT + ICP + POSITIONING], generate 20 distinct ad concepts. Each concept: 1-line premise, hook line, format recommendation (UGC / reaction / cinematic / BTS vlog), funnel position (TOF / MOF / BOF), primary angle. Prioritize novelty over polish.
```

### Agent 3.2 — Hook Line Factory
**Role**: Writes 30 hook variations for a given concept.
**Trigger**: When testing a scaling concept.
**Prompt**:
```javascript
For the concept "[CONCEPT]", write 30 hook line variants across 6 hook archetypes (question / shock / contradiction / mystery / reveal / claim). Each hook: under 12 words, no fluff, breaks pattern in first 3 words.
```

### Agent 3.3 — Script Doctor
**Role**: Rewrites weak scripts into tight, punchy versions.
**Trigger**: When a script feels flat.
**Prompt**:
```javascript
Given this script: [PASTE]. Diagnose weak beats. Cut every unnecessary word. Sharpen the hook. Tighten the middle. Rewrite the CTA. Output the tightened version at 60-70% of original word count.
```

### Agent 3.4 — Format Selector
**Role**: Picks the optimal ad format for a given concept + funnel position.
**Trigger**: Before production briefing.
**Prompt**:
```javascript
For [CONCEPT + FUNNEL POSITION + AUDIENCE TEMPERATURE], recommend the optimal ad format: UGC talking-head, reaction UGC, cinematic scene, BTS vlog, 1-photo-to-6-shots, or carousel. Justify with expected hook rate + CTR.
```

### Agent 3.5 — Reaction Beat Architect
**Role**: Writes the 3-act reaction UGC script structure.
**Trigger**: When producing reaction-format ads.
**Prompt**:
```javascript
For [PRODUCT + BEAT ARCHETYPE from 7 reaction beats], write the 3-act reaction structure: Act 1 hook reaction (0-5s) / Act 2 problem expansion (5-15s) / Act 3 product demo + resolution (15-30s). Under 100 total words.
```

### Agent 3.6 — Storyboard Sketcher
**Role**: Produces a 6-shot storyboard from a script.
**Trigger**: Before Seedance production.
**Prompt**:
```javascript
Given script: [PASTE]. Produce a 6-shot storyboard: Hook close-up / Lifestyle in-hand / Application / Reaction / Environmental wide / CTA hero. Per shot: framing, camera language, subject action, product placement, duration.
```

### Agent 3.7 — CTA Variant Writer
**Role**: Writes 10 CTA variations optimized for different funnel positions.
**Trigger**: Every ad, every time.
**Prompt**:
```javascript
For [OFFER + FUNNEL POSITION], write 10 CTA variants: 3 for cold audience (curiosity-first), 3 for warm (desire-first), 3 for hot (urgency-first), 1 wildcard. Each under 6 words.
```

### Agent 3.8 — Comparative Ad Composer
**Role**: Writes side-by-side comparison ads without naming competitors.
**Trigger**: When positioning against a market leader.
**Prompt**:
```javascript
For [BRAND vs GENERIC CATEGORY], write 5 comparative ad concepts that establish superiority without naming competitors. Each: hook, comparison structure, proof anchor, resolution.
```

### Agent 3.9 — POV Angle Generator
**Role**: Produces distinct POVs to test per concept.
**Trigger**: When testing angle variations at scale.
**Prompt**:
```javascript
For [CONCEPT], generate 8 POV angles: founder / customer / expert / skeptic / friend / analyst / practitioner / outsider. Per POV: opening line + framing shift + emotional register.
```

### Agent 3.10 — Series Arc Planner
**Role**: Plans a 4-week sequential ad series with narrative continuity.
**Trigger**: When running educational or warm-up campaigns.
**Prompt**:
```javascript

## 👥 Team 5 — Performance Analysis Agents (10)

What worked after deploy. What to iterate next.

### Agent 5.1 — Hour-24 Matrix Runner
**Role**: Runs the kill-or-scale matrix at hour 24 post-deploy.
**Trigger**: 24 hours after every ad batch launches.
**Prompt**:
```javascript
Given batch data [PASTE: ad, spend, hook rate, hold rate, CTR, CPA]. Run kill/hold/scale matrix. Cite thresholds. Recommend action per ad. No hedging.
```

### Agent 5.2 — Hook Rate Diagnostician
**Role**: Explains WHY hook rate collapsed.
**Trigger**: When hook rate is under 30%.
**Prompt**:
```javascript
For this ad [PASTE OUTPUT + HOOK RATE], diagnose why hook rate is below threshold. Isolate: opening frame issue / hook line issue / format-audience mismatch / thumbnail issue. Recommend 3 specific fixes.
```

### Agent 5.3 — Hold Rate Auditor
**Role**: Explains where viewers dropped off.
**Trigger**: When hold rate collapses at second 8-15.
**Prompt**:
```javascript
For this ad [PASTE + RETENTION CURVE], identify the drop-off point second. Diagnose: pacing issue / product intro placement / dialogue timing / visual monotony. Recommend fix.
```

### Agent 5.4 — Format-Audience Matcher
**Role**: Identifies which format wins which audience.
**Trigger**: Weekly performance review.
**Prompt**:
```javascript
Given last week's data across [FORMATS: UGC / reaction / cinematic / BTS vlog / carousel] and [AUDIENCES: cold / warm / hot / lookalike], identify format-audience winners. Kill format-audience mismatches. Scale winners.
```

### Agent 5.5 — Winning Beat Extractor
**Role**: Extracts what made a scaling ad win.
**Trigger**: When an ad hits scale (>2x ROAS at $500+/day).
**Prompt**:
```javascript
For this scaling ad [PASTE OUTPUT + METRICS], extract the winning beat: hook mechanic / product reveal timing / emotional arc / production element. Turn the winning beat into a reusable pattern for future ads.
```

### Agent 5.6 — Fatigue Detector
**Role**: Flags creative fatigue before performance collapses.
**Trigger**: Every 72 hours on high-spend ads.
**Prompt**:
```javascript
For ads spending >$500/day for 7+ days, check for fatigue signals: frequency > 3.5, CTR declining >20% week-over-week, CPA rising >15%. Flag fatiguing ads. Recommend fresh variants.
```

### Agent 5.7 — Cross-Platform Performance Compare
**Role**: Compares the same ad across Meta vs TikTok vs YouTube.
**Trigger**: Weekly.
**Prompt**:
```javascript
For this ad live across [PLATFORMS], compare performance per platform: hook rate, hold rate, CTR, CPA. Identify platform-native winners vs one-size-fits-all losers. Recommend platform-specific variants.
```

### Agent 5.8 — Cohort Attribution Sleuth
**Role**: Isolates which ads convert which cohorts.
**Trigger**: Monthly.
**Prompt**:
```javascript
Given attribution data [PASTE], isolate: which ads acquired first-time buyers vs which drove repeat purchase vs which drove UGC generation. Recommend ad-mix rebalancing.
```

### Agent 5.9 — Winning Variant Cloning Director
**Role**: Writes the next 5 variants of a scaling ad.
**Trigger**: Immediately when an ad hits scale.
**Prompt**:
```javascript
For scaling ad [PASTE], write 5 variant briefs: same core mechanic, 3 hook variations + 2 format variations. Feed these to production before the scaling ad fatigues.
```

### Agent 5.10 — Kill List Compiler
**Role**: Compiles the weekly kill list to feed back to concept generation.
**Trigger**: End of every week.
**Prompt**:
```javascript
Compile this week's kill list: [PASTE FAILED ADS]. Identify recurring failure patterns (bad hook / wrong format / weak product moment / off-brand). Feed patterns back to Concept Generator (Agent 3.1) as anti-patterns to avoid.
```
