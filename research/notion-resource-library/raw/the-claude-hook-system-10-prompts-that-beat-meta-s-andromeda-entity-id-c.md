## ⚙️ The Hidden Mechanism — Andromeda's Entity ID Cap
Meta's Andromeda algorithm (rolled out Q4 2025, refined through Q1-Q2 2026) introduced a brutal change most operators haven't caught yet:
**Meta now reads structurally similar ads as ONE entity ID, no matter how different the hooks are.**
What this means in practice:
→ You write 10 hook variations for 1 product<br>→ All 10 are UGC selfies, same character archetype, same setting<br>→ Andromeda groups them: same entity ID<br>→ Meta serves them to the same audience pool<br>→ Your 10 ads compete with themselves for the same impressions<br>→ You think you're testing 10 ads. You're testing 1.
The pre-Andromeda playbook (write more hooks, ship more variations) is dead. Quantity stopped working. Diversity moved up the funnel.
The new playbook: **structural format diversity, not hook variation diversity.** Meta groups by VISUAL FORMAT (UGC selfie, podcast clip, street interview, walk-and-talk, POV vlog), not by hook copy. Wrap 1 concept in 4 structural formats and you get 4 distinct entity IDs that Meta serves to 4 distinct audience pools.
Same product. Same claim. Same audience target. 4x the reach. The fix is not better hooks. The fix is **structural wrapping of the same concept** — the thing that lets 1 idea reach 4 audience pools instead of competing with itself.

## ⚙️ The 10 Prompts (Copy-Paste Library)
Save each as a Claude slash command or as named messages in your project. Run in order.
### Prompt 1 — ICP Relevance Map
```javascript
Run the ICP Relevance Map for [BRAND NAME].

For the ICP loaded in our project context, output
a structured table:

| Pain | Frequency | Severity | Trigger | Aspiration |
|---|---|---|---|---|

Generate 8-12 rows covering:
- The 3 most frequent pains the ICP experiences
  weekly
- The 2-3 most severe pains (the ones that hurt
  most)
- The 2-3 emotional triggers tied to those pains
- The 2-3 aspirations (what they want INSTEAD)

For each row:
- Frequency: how often the pain occurs (daily,
  weekly, monthly, situational)
- Severity: how much it hurts (1-10)
- Trigger: what event/moment causes the pain
- Aspiration: the dream state if the pain went
  away

Output the table only. No commentary.
```
### Prompt 2 — Relevance Hook Bank
```javascript
Using the ICP Relevance Map from Prompt 1, write
20 hook variations.

Rules:
- Each hook tied to 1 row from the ICP map
- 6-12 words per hook
- Specific, not generic
- No "Most..." openers
- No clickbait — relevance over hype
- Mix question hooks, statement hooks, contrast
  hooks, observation hooks

Output format:
1. [Hook text] → Pain it ties to: [PAIN]
2. [Hook text] → Pain it ties to: [PAIN]
...

Rank all 20 by predicted relevance (1 = highest,
20 = lowest).
```
### Prompt 3 — Curiosity Open Loops + Mechanism
```javascript
Take the top 12 hooks from Prompt 2.

For each, add a curiosity open loop + mechanism
reveal.

Curiosity open loop = a question or hint that
makes the viewer need to know the answer.

Mechanism reveal = the specific HOW behind the
result (the ingredient, the trick, the system,
the unexpected cause).

Output format:
Hook: [original hook]
Curiosity loop: [the question that opens the
loop]
Mechanism reveal: [the specific HOW that closes
the loop]
Full hook + first line: [combined version
ready for ad]
```
### Prompt 4 — Emotion Trigger Hooks
```javascript
Take the 12 hooks from Prompt 3.

Layer in emotion triggers. For each hook, identify
the dominant emotion that will land hardest:

- Fear (loss aversion, urgency, regret)
- Hope (transformation, possibility, relief)
- Anger (frustration with status quo, injustice)
- Surprise (counter-intuitive truth, plot twist)
- Curiosity (already added in Prompt 3, intensify)
- Pride (status, recognition, achievement)

For each hook, rewrite to amplify the dominant
emotion without losing the curiosity loop or
mechanism reveal.

Output the 12 emotion-weighted hooks ranked by
predicted emotional pull.
```
### Prompt 5 — Qualified Hook Filter
```javascript
Take the 12 hooks from Prompt 4.

Filter out any hook that would attract the WRONG
audience.

Hooks must pre-qualify the buyer — meaning the
hook itself filters for someone in our ICP, not
just any engagement-seeker.

For each hook, evaluate:
- Does this hook attract our target ICP? (yes/no)
- Does this hook repel the wrong audience?
  (yes/no)
- Is the implied buyer aligned with our pricing
  and offer?

Keep only the hooks that pass all 3 filters. Drop
the rest.

Output: 6-8 qualified hooks with reasoning for
why each one stayed.
```
### Prompt 6 — Organic-Feed Visual Hooks
```javascript
Take the 6-8 qualified hooks from Prompt 5.

For each, pair with an organic-feed visual concept
that would stop a scroll on Meta/TikTok.

Visual concept must:
- Look like organic content (not an ad)
- Show something specific in the first frame
- Avoid generic stock imagery
- Match the hook's emotion

Output format:
Hook: [hook text]
Visual concept (frame 1): [specific visual
description]
Visual concept (continuing): [how the visual
unfolds in seconds 2-5]
Reason this stops the scroll: [the specific
mechanic]
```
### Prompt 7 — Closeup + Expression Hooks
```javascript
Take the hook + visual pairs from Prompt 6.

Add closeup framing + facial expression specs.

For each:
- Closeup type: extreme closeup of [WHAT —
  product detail, hand, eyes, mouth, etc.]
- Expression: [the specific micro-expression
  that lands the emotion]
- Eye direction: [where the subject looks during
  the closeup]
- Hold duration: [how long the closeup holds in
  the ad]

Output production-grade visual specs for each
hook ready for any creative tool.
```
### Prompt 8 — Immediate-Context Hooks
```javascript
Take the closeup hooks from Prompt 7.

Root each hook in immediate user context —
the moment, place, mood, or state the viewer is
likely in when they encounter the ad.

Context examples:
- Morning routine (in pajamas, just woke up)
- Mid-day scroll break (at desk, frustrated)
- Evening wind-down (couch, tired)
- Weekend chill (saturday morning, coffee)
- Pre-event panic (an hour before [event],
  stressed)

For each hook, write the 1-sentence context
opener that puts the viewer in the moment
BEFORE the hook lands.

Output format:
Context: [the immediate moment opener]
Hook: [the hook from Prompt 7]
Visual: [the visual from Prompts 6-7]
```
### Prompt 9 — Entity-ID Diversity (The 4 Structural Wraps)
```javascript
Take the top 4 immediate-context hooks from
Prompt 8.

For each of those 4 hooks, wrap it in the 4
structural formats:

1. Podcast wrap
- 2-person seated conversation
- Microphone visible
- Conversational tone (not scripted-feeling)
- Hook delivered as a casual reveal during the
  conversation

2. Street interview wrap
- Reporter approaches stranger
- Urban backdrop (sidewalk, store front, plaza)
- Hand-held microphone visible
- Hook delivered as the stranger's answer to
  a question

3. Walk-and-talk wrap
- Solo creator walking, talking direct-to-camera
- Dynamic background (street, hallway,
  outdoor path)
- Hook delivered mid-stride as a personal
  observation

4. POV (first-person) wrap
- Camera = viewer's eyes
- Hands visible interacting with product
- Hook delivered as voiceover or text overlay
  while hands demonstrate

For each of the 4 hooks × 4 wraps = 16 concepts.

But you don't need all 16. Pick the TOP 4 wraps
(1 hook per wrap, 4 total) that maximize entity
ID diversity in Meta's algorithm.

Output the 4 winning wraps with full specs.
```
### Prompt 10 — Production-Ready Hook Brief
```javascript
Take the 4 winning wraps from Prompt 9.

For each, write a production-ready brief in this
format:

CONCEPT NAME: [1-line concept name]
ENTITY ID TYPE: [Podcast / Street / Walk-and-Talk
/ POV]
TARGET AUDIENCE POOL: [the audience pool this
wrap targets in Meta]

Hook (first 3 seconds of ad):
"[exact dialog or text]"

Visual (frame-by-frame):
- Frame 1 (0-2s): [setup shot]
- Frame 2 (2-5s): [reveal shot]
- Frame 3 (5-10s): [demo/result shot]
- Frame 4 (10-15s): [CTA shot]

Setting: [specific location]
Character archetype: [age, look, wardrobe, vibe]
Product placement: [hand position, height, angle]
Audio direction: [tone, pacing, music notes]
CTA: [exact CTA copy]
Recommended creative tool: [MakeUGC / Maxfusion /
Higgsfield Supercomputer]

Output all 4 briefs ready to copy-paste into the
chosen creative tool.
```
After all 10 prompts run, you have 4 distinct entity ID briefs ready for deployment.

## ⚙️ What NOT to Do
→ Don't skip Prompt 1 (ICP Relevance Map). Without it, every downstream prompt produces generic output. The map is the foundation.
→ Don't run the 10 prompts out of order. Each one builds on the previous. Skipping Prompt 4 (Emotion) breaks Prompt 5 (Qualification).
→ Don't write 10 hook variations in the same structural format. Meta groups them as 1. Use the 4 structural wraps instead — same concept, 4 different visual structures.
→ Don't deploy all 16 outputs from Prompt 9. Pick the top 4 wraps (1 per structural type). 4 wraps = 4 entity IDs. Deploying 16 means Meta groups them back into 1-2 entity IDs.
→ Don't use the Hook System for cold experimentation. The system compounds — run it on validated concepts. Use research from other lead magnets to identify validated concepts first.
→ Don't ignore Andromeda's grouping after deploy. If 2 of your 4 wraps are showing similar audience pool overlap, Meta is grouping them. Differentiate the visual structure harder.
→ Don't replace the ICP Relevance Map every week. Update it monthly with learnings. The map is supposed to compound across campaigns.
→ Don't hand off briefs without the recommended creative tool spec. Each wrap type has a best-fit tool. Routing to the wrong tool produces output that doesn't match the wrap's strengths.
→ Don't use the system on competitor copying. The 10 prompts are calibrated for original concept generation. Cloning competitor hooks bypasses the qualification filter (Prompt 5) and produces hooks that already lost to Andromeda.
→ Don't run the matrix at hour 12 or hour 48. Hour 24 is calibrated to Meta's reporting stability. Earlier = noisy data. Later = winners already fatiguing.
→ Don't expect every wrap to win. Typically 1-2 of the 4 wraps dominate per brand. The matrix tells you which. Compound the winner across future concepts.
