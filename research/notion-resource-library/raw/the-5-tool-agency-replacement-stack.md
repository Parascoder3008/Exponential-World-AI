## ⚙️ The Master Meta MCP Setup
Step-by-step setup for the autopilot publishing layer.
### Install the Meta MCP Server
Pick one of:
→ Pipeboard's Meta Ads MCP (open source): `npm install -g @pipeboard/meta-ads-mcp`<br>→ Community alternatives on GitHub
### Generate Meta API Token
1. Open Meta for Developers → Create or pick an app
2. Add Marketing API as a product
3. Generate system user access token with scopes: ads_read, ads_management, business_management
4. Copy token
### Add to Claude Desktop Config
Edit `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS):
```json
{
  "mcpServers": {
    "meta-ads": {
      "command": "meta-ads-mcp",
      "env": {
        "META_ACCESS_TOKEN": "[YOUR TOKEN]",
        "META_AD_ACCOUNT_ID": "act_xxxxxxxxx"
      }
    }
  }
}
```
Restart Claude Desktop. Verify connection via `/mcp` command.
### Authorize Claude to Take Action
By default, MCP allows Claude to READ data. To enable AUTOPILOT publishing + scaling, add explicit permissions in your Claude Project instructions:
```plain text
You are authorized to:
- Create ads on Meta Ads Manager
- Set budgets (within $0-$500/day per ad
  range)
- Pause ads (kill decisions)
- Increase budgets (within +100% per 24h)
- Pull performance data continuously

You are NOT authorized to:
- Spend over $500/day per ad without operator
  approval
- Modify ad account settings
- Create or delete campaigns
- Access financial data beyond ad spend
```
The permission model: Claude executes within bounded autonomy. Anything outside the bounds requires operator approval.

## ⚙️ What NOT to Do
→ Don't enable Phase 4 autopilot on Day 1. Validate Phases 1-3 manually for 1-2 weeks first.
→ Don't give Claude unbounded autonomy. Always set spend caps + scaling limits in the project instructions.
→ Don't skip the statistical significance gate. Killing ads below $30 spend is the most common operator mistake — even autopilots make it if not configured correctly.
→ Don't scale faster than +100% per 24h. Algorithm learning phase resets. Slow scaling preserves wins.
→ Don't run autopilot on accounts under $1K/month spend. Statistical significance rarely reached. Autopilot decisions become noise.
→ Don't replace the entire agency on Day 1. Run the 5-tool stack ALONGSIDE the agency for 30-60 days to validate. Then transition.
→ Don't share Meta API tokens. Treat them like passwords. Rotate quarterly.
→ Don't run multiple brands in 1 Claude Project. Each brand needs its own project with its own knowledge + ad account access.
→ Don't expect immediate revenue lift. Autopilot's value is consistency + cost reduction, not magic ROAS gains.
→ Don't ignore weekly strategy reviews. Autopilot handles tactics. Strategy still needs operator judgment.
→ Don't try to autopilot non-Meta platforms via this stack. Meta MCP only. For TikTok + Snap, you need their respective MCPs (or manual + scheduling tools).
