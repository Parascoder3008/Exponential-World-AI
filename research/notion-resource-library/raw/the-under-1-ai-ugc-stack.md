## ⚙️ Step 4 — Lock Voice Consistency Across the Batch
The trick that prevents the most common "AI tell" — voice drift across clips.
Standard approach: every Seedance generation creates a fresh voice = different voice in every clip = audience reads as "AI."
This stack approach:
1. Generate the first clip for each creator with full attention
2. Confirm the voice quality matches the creator's archetype
3. Save the voice clone as a reusable asset (ElevenLabs voice library or Seedance saved voice)
4. Every subsequent clip for that creator references the locked voice clone ID
Result: 1 creator = 1 voice across 100+ clips. Audience reads as "1 consistent creator" instead of "100 random AI clips."

## ⚙️ Step 5 — Scale to Any Video Length (The Infinite Scaling Protocol)
Most AI video models charge per-second, so a 30-second clip costs 6x a 5-second clip. The infinite scaling protocol breaks this cost ceiling.
The mechanic:
1. Generate the first 5-second clip with full character + voice locks
2. Use the last frame of clip 1 as the reference for clip 2
3. Continue voice clone reference into clip 2
4. Repeat for clip 3, 4, 5, etc.
5. Stitch in CapCut with smooth cuts at the chain points
Result: a 30-second video = 6 chained 5-second clips. Cost: 6 × $0.20-$0.40 = $1.20-$2.40. Still cheaper per-second than Sora at 30s ($3-$6+).
For 60+ second videos, the protocol scales linearly. Cost per second stays constant.

## ⚙️ The Consistent Voice Protocol
The voice clone setup that makes 1 creator = 1 voice across 100+ clips.
### Initial Voice Clone Setup (one-time per creator)
1. Generate the first Seedance clip for the creator
2. Listen back to the audio — confirm the voice matches the creator's archetype
3. If yes, extract voice clone:
	- In ElevenLabs: upload the audio, save as new voice in library, get voice ID
	- In Seedance native: use "save voice from clip" feature, get voice ID
4. Document the voice ID in your creator profile reference
Total setup time: 5-10 minutes per creator.
### Per-Clip Voice Reference (every subsequent generation)
In every Seedance prompt for that creator, include:
```javascript
Voice clone reference: @[VOICE CLONE ID]
Lock audio synthesis to this voice clone. Do
not generate fresh voice — use the saved clone
verbatim.
```
Result: every clip for that creator uses the identical voice. Audience hears 1 person, not 100 different AI voices.
### Voice Diversification Across Account Network
For mass-scale organic across thousands of accounts, use 20-50 distinct voice clones (1 per AI creator archetype). Each account uses its own creator's locked voice. Account audiences hear "1 consistent person" per account.

## ⚙️ The Infinite Scaling Protocol
Standard AI video pricing: per-second cost stays the same, so 30-second clip = 6x cost of 5-second clip.
The protocol that breaks the cost ceiling:
### The Chained Generation Mechanic
1. Generate first 5-second clip with full character + voice locks
2. Extract the LAST frame of clip 1 (the final still before fadeout)
3. Use that frame as the REFERENCE for clip 2
4. Carry the voice clone ID forward into clip 2's audio synthesis
5. Repeat the script continuation pattern for clip 3, 4, 5, 6
6. Stitch in CapCut with imperceptible cut between chain points
### Cost Math
5-second clip: $0.20-$0.40<br>6 × 5-second clips chained = 30-second video<br>Cost: $1.20-$2.40 total

- Sora 30s: $3-$6+

- Kling 30s: $1.80-$4+
For ANY video length, the under-$1 stack chains generations to scale duration without scaling per-second cost.

→ Don't generate without all 8 hyper-realistic anchors. Skip any one and Seedance output reads "AI" — defeating the under-$1 economics.
→ Don't use fresh voice per generation. Lock voice clones once per creator and reuse. Voice consistency is what separates "1 real creator" from "100 random AI clips."
→ Don't run 1 account at high volume. Spread across 50-500 accounts at low daily cadence (1-3 posts/day per account). Single-account volume triggers spam flags.
→ Don't compare model brands (Sora vs Veo vs Kling). Compare full stack costs. Model-only comparison misses 60% of actual cost.
→ Don't skip the account warming phase. Affiliate links on fresh accounts get flagged. Pre-warm 30-60 days before monetizing.
→ Don't use the same creator across multiple unrelated niches. Each account = 1 niche = 1 consistent creator.
→ Don't generate videos longer than 60s without testing the chain protocol first. Chained generations can drift after 6-8 clips — adjust the chain protocol based on which segments fail.
→ Don't run the under-$1 stack for brand pillar / cinematic ads. Use Lovart or Higgsfield Pitch Deck for those. Under-$1 is for UGC volume.
→ Don't ignore the affiliate compliance layer (covered in the Affiliate Playbook). Every monetized video needs FTC + program disclosure.
→ Don't expect immediate revenue. Account warming + algorithm learning takes 30-90 days. Real monetization scale starts month 3+.
