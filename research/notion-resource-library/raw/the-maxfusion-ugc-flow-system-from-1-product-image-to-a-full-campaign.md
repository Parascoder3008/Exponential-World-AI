## Step 2 — Understand The 5-Node Flow Architecture
Open the flow. You'll see 5 node types wired together. This is what each does:
### Node Type 1 — Product Image (center anchor)
The fixed visual anchor for the entire campaign. Every actor in every variation holds or interacts with this image.
→ Drop your product PNG here (1024×1024, transparent or white background)<br>→ The flow references this node downstream — change it and every generation updates
### Node Type 2 — Actor Prompt Nodes
6-8 prompt nodes describing each actor archetype. Each prompt defines: gender, age, hair, skin tone, wardrobe, setting, and signature style. The flow generates 1 image per prompt.
These are the "different look, setting, personality" lines from the post.
### Node Type 3 — Image Generation Nodes
Receive the prompt + the product image as inputs. Output: 1 AI actor holding your product in the described setting. This is where Banana Clone + RIZZ's identity engine produce the photoreal actors.
### Node Type 4 — Video Generation Nodes
Receive the image generation output as the locked reference. Output: 1 15-second UGC video with the actor delivering the script. Lipsync, emotion tags, and motion are all driven from this node.
### Node Type 5 — Script Input
The dialog and emotion tags that every actor will deliver. Lock this once. Every video in the campaign uses the same script with different actors.

## The Copy Lab + Banana Clone Workflow (Steal-the-Structure)
This is the part most operators sleep on. Maxfusion lets you reverse-engineer any winning competitor ad and recreate the format.
### How it works:
1. Find a winning competitor UGC ad (running 30+ days on Meta = signal of performance)
2. Drag the video into Maxfusion's Copy Lab
3. Copy Lab extracts: transcript, scene-by-scene breakdown, keyframes
4. For each keyframe, run Banana Clone → get a copyright-free lookalike actor
5. Drop the Banana Clone outputs into your flow as new actor nodes
6. The flow regenerates the format with your product + your script
You just legally cloned a winning ad format in 15 minutes.
### Copy Lab prompt:
```javascript
Upload this competitor video to Copy Lab. Extract:
1. Full transcript with timing
2. Scene breakdown (every cut)
3. Keyframes from each scene
4. Camera angle notes per scene
5. Lighting + setting notes per scene
6. Emotional beats per scene

Output: a scene-by-scene blueprint I can rebuild
with my product + my script + my Banana Clone actors.

Reference video: [PASTE COMPETITOR AD URL]
```
### Banana Clone prompt:
```javascript
Drag this reference image into Banana Clone.

Generate a copyright-free lookalike that preserves:
- Setting and environment
- Wardrobe style (not exact garment)
- Camera angle and framing
- Lighting direction

Change enough to legally differ from the source:
- Face structure (similar archetype, different
  individual)
- Hair color or styling (slight variation)
- 1 accessory swap (jewelry, watch, etc.)

Reference image: [PASTE COMPETITOR KEYFRAME]
```

## What NOT to Do
→ Don't skip the flow clone step. The pre-built architecture is the entire point. Rebuilding from scratch wastes 90% of the value.
→ Don't run the flow with the demo's actor prompts. Customize them for your ICP. The flow's value is in the architecture, not the demo's specific personas.
→ Don't use generic product images. The product is the visual anchor. Use a clean, well-lit reference photo. Run Banana Clone first if needed.
→ Don't deploy all 6 generated variations on day 1. Run the matrix on 4-5. Use the survivor data to inform next week's flow run.
→ Don't ignore Copy Lab. It's the 10x speed unlock for steal-the-structure workflows. Every operator should be feeding Copy Lab their top 5 competitor ads weekly.
→ Don't localize before validating in 1 language. Lock the winning variation in English first. Then localize the winner to 8+ markets — not all 6 untested variations.
→ Don't change the script across the 6 actor variations on the first run. Keep script constant, vary the actor. Audience preference for archetype is the most useful signal.
→ Don't use this as your only ad type. Mix Maxfusion UGC with cinematic ads (from the Production Board System), static product hero shots, and direct-response formats. UGC builds volume; the portfolio holds long-term.
→ Don't skip the kill-or-scale matrix after generation. The flow gives you volume. The matrix turns volume into wins.
→ Don't store flows scattered across projects. Build a "Master Flows" folder in Maxfusion with 1 flow per vertical. Compound your library.

<td>Use a custom voiceover (ElevenLabs clone or Maxfusion stock voice) instead of relying on auto-script lipsync.</td>

<td>Actor face changes mid-clip</td>
<td>Strengthen the reference image fidelity in the video node. Use Banana Clone for cleaner reference frames.</td>

<td>Generation hangs or fails</td>
<td>Reduce parallel node count from 6 to 3, run in 2 batches.</td>

<td>The reference video has cluttered cuts. Use a cleaner source ad with distinct scene boundaries.</td>
