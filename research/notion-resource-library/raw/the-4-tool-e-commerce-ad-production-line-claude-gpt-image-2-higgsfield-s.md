## ⚙️ The Hidden Mechanism — Why a 4-Tool Chain Beats Single-Tool AI Ad Generation
Every single-tool AI ad workflow has the same broken loop:
1. Operator opens Tool A, writes a long brief, generates a hero clip
2. Tries to extend with Tool B, re-briefs from scratch
3. Tool B's output drifts from Tool A's output (different character, different palette, different feel)
4. Stitches in CapCut hoping the audience doesn't notice
5. Audience notices in the first 3 seconds
Each tool is fine at its job. The break is **between tools** — every handoff loses brief context.
The 4-tool chain fix is structural:
→ **Claude** is the orchestrator. Brief once. Claude writes the script, the image prompt, the video prompt — all from the same context.<br>→ **GPT Image 2** generates reference images that hold character identity (face, body, outfit) using Claude's structured prompt with the right anchors.<br>→ **Higgsfield Marketing Studio** receives the reference image + Claude's ad-style brief and executes the chosen style (1 of 9) without re-interpreting the character.<br>→ **Seedance 2.0** receives the Higgsfield output as the visual reference + Claude's camera language prompt and animates with motion timeline locked.
The face reference travels through all 4 tools. Identity holds across every step.
The fix is not better individual tools. The fix is **Claude orchestrating the chain** — the thing that lets the same character + product + brand feel persist from script to finished ad.

## ⚙️ The 4-Tool Chaining Protocol
The trick that maintains face reference through every tool:
1. **GPT Image 2 generates** a character + product reference image with identity lock anchors
2. **Save the reference image** as a locked asset (high resolution PNG, 4K)
3. **Higgsfield Marketing Studio receives** the reference image as the primary input. Higgsfield interprets the image as the locked character + product, not as a starting point to drift from
4. **Higgsfield outputs** a Marketing Studio variation (image or short clip) executing the chosen ad style — still referencing the original character + product
5. **Seedance 2.0 receives** the Higgsfield output as the visual reference + Claude's motion timeline
6. **Seedance generates** the final video with character + product locked across all frames
Every tool inherits the reference from the previous step. No re-briefing. No re-describing. The character + product travels through 4 tools without drift.
The protocol works because each tool's input is the previous tool's output. The reference image is the contract.

## ⚙️ What NOT to Do
→ Don't run the chain without installing the Claude Skill first. The Skill IS the orchestration. Without it, you're back to 4 separate tool sessions.
→ Don't skip uploading brand kit + ICP + voice samples to Project Knowledge. Without grounding, Claude generates generic outputs.
→ Don't approve outputs without reading them. Quick eyeball before downstream generation saves credits.
→ Don't skip the GPT Image 2 reference step. Going directly to Higgsfield + Seedance without a locked reference loses identity.
→ Don't change the ad style mid-chain. Pick 1 of 9 at brief time. Switching styles after Output 3 breaks the chain.
→ Don't use this for non-DTC content. The Skill is calibrated for e-commerce ads. Other ad types may need different prompt structures.
→ Don't override Claude's outputs without reason. Claude's prompts are calibrated against winning patterns. Manual edits often introduce drift.
→ Don't expect 100% identity hold. 90-95% is realistic. 1-2 in 20 generations need a regenerate.
→ Don't run multiple brands in 1 Claude Project. Each brand needs its own project with its own knowledge base.
→ Don't skip the troubleshooting table (Section 14). Most failures map to specific fixes.
→ Don't replace your specialty workflows with this one. The 4-tool chain handles daily production. Specialty systems still earn their place for specific formats.
