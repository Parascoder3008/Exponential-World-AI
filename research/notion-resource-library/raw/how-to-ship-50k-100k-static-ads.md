## ⚙️ Step 2 — The Swiss Typography Specification Block
The typography spec is what separates premium from amateur. Add these details to override or reinforce the master prompt.
### The Swiss Typography Rules
```javascript
TYPOGRAPHY REQUIREMENTS:
- Primary typeface: SF Pro Display (Apple
  system aesthetic) OR Helvetica Neue (Swiss
  original) OR Inter (open-source modern
  equivalent)
- Weight hierarchy:
  - Headline: 800 (Extra Bold) or 900 (Black)
  - Subheading: 400 (Regular) or 500 (Medium)
  - Features: 500 (Medium) or 600 (Semi-Bold)
- Kerning: tight but readable (Swiss modernist
  style)
- Line height: 1.1-1.2 for headlines, 1.4-1.5
  for body
- Alignment: left-aligned only, no centered
  text
- Case: sentence case for subheading,
  UPPERCASE for headline in Nike style, OR
  Sentence case for softer luxury
- Color: high-contrast black on light
  background OR high-contrast white on dark
  background — never grey text
- NO decorative type
- NO scripts
- NO retro or vintage fonts
- NO gradient text fills
```
### When to Use UPPERCASE Headlines
UPPERCASE = performance / athletic / bold:
- "PURE PERFORMANCE"
- "PERFORM"
- "EVERY STEP"
- "BUILT FOR MOTION"
- "ENGINEERED FOR SPEED"
Sentence case = luxury / minimalist / considered:
- "Designed for movement"
- "Style meets function"
- "The everyday reimagined"
- "Considered craftsmanship"
Match the case to your brand's positioning tone.

## ⚙️ Step 4 — The 5-Angle Bottom Strip Composition Rules
The bottom strip is what makes the ad feel like an official product page. Get this wrong and the whole thing looks amateur.
### The 5 Angles (Standard)
1. **Front view** — straight-on hero angle
2. **45-degree angle** — 3/4 view showing depth
3. **Side view** — profile shot
4. **Back view** — rear-facing angle
5. **Top-down or close-up detail** — bird's eye OR macro shot of detail
### Composition Rules
→ **Equal sizing** — all 5 angles at same scale<br>→ **Equal spacing** — even gaps between each angle<br>→ **Consistent lighting** — same light source direction across all 5<br>→ **Consistent background** — subtle brand-color background across all<br>→ **Consistent scale** — product occupies same % of frame in each angle<br>→ **No overlap** — clean separation<br>→ **Aligned baseline** — all products sitting on the same visual baseline
### Common Failure Modes
→ Different lighting between angles = looks composite<br>→ Different sizes = amateur<br>→ Overlap = cluttered<br>→ Missing angles = incomplete<br>→ Baseline misalignment = sloppy
If any of these happen, regenerate with explicit rule enforcement in the prompt: `"BOTTOM STRIP: 5 angles, equal sizing, equal spacing, aligned baseline, consistent lighting from top-left, subtle brand-color background."`
### Alternative Bottom Strip Configurations
**4 angles** (for cleaner minimalist look):
- Front / 45° / side / back
**3 angles + detail** (for detail-focused brands):
- Front / side / back + hero macro detail
**5 outfit variations** (for apparel with color options):
- Same style in 5 different colorways
Adapt based on your brand's storytelling need.

```javascript
Animate this static Nike-tier hero ad into a
5-second premium campaign video. Preserve
exact composition, product identity, layout,
and aesthetic of the source image.

Add subtle motion:
→ Hero product: very subtle rotation or slight
  parallax shift (5-10 degree slow arc over 5
  seconds)
→ Bottom strip: gentle staggered fade-in from
  left to right
→ Headline text: subtle typography animation
  (fade in over first second, hold, no motion
  after)
→ Camera: gentle push-in from wide to medium
  (3-5% zoom over 5 seconds)
→ Lighting: hold consistent with source image

Physics rules:
→ Subtle motion only, no sudden movements
→ Product remains stable + centered
→ Text animations complete before second 2 so
  viewer can read
→ ARRI Alexa cinematic aesthetic preserved
→ No flashy transitions

Duration: 5 seconds
Aspect ratio: match source (4:5 or 9:16)
Resolution: 4K
```

## ⚙️ What NOT to Do
→ Don't skip the reference product photo. GPT Image 2 needs the source to preserve product identity. Text-only prompts produce generic footwear.
→ Don't use low-resolution product photos. Sub-4K source = imprecise identity preservation. Modern DSLR captures 4K natively.
→ Don't try to force a different aspect ratio outside 4:5 without adjusting the layout balance. 4:5 is optimized for the Nike-tier composition. 16:9 requires rebalancing bottom strip position.
→ Don't over-brief the gradient palette. Let auto-extraction do its work first. Override only if the extracted palette misses brand context.
→ Don't use icons on features. Text-only. Icons make it look like corporate PowerPoint, not premium footwear campaign.
→ Don't skip the 5-angle bottom strip. Removing it kills the "official product page" feel. It's the 30% that makes it look like a real brand campaign.
→ Don't use dramatic music if animating. Subtle instrumental only. Match Nike's brand-ad music tone.
→ Don't use this system for products with weak visual identity. If your shoe looks generic in the source photo, no hero layout will save it. Fix the shoe design + photography first.
→ Don't skip Figma / Photoshop polish for final print deployment. GPT Image 2 output is 95% there. Print requires exact brand color match.
→ Don't measure hero ad performance on CTR alone. Hero ads drive brand recall + saves + product-page conversion. Measure on full-funnel signal.
→ Don't reuse the same hero across quarters without refresh. Brand fatigue applies to hero ads too. Refresh quarterly minimum.
→ Don't ignore Swiss typography rules. Fancy fonts kill the entire premium feel. SF Pro / Helvetica / Inter only.
