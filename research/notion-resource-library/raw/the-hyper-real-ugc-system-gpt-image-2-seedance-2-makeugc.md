## ⚙️ Step 1 — Build Your Reference Image Library
This is the step everyone skips. Don't.
→ Open Pinterest, Instagram, or TikTok<br>→ Search for UGC content in your niche ("skincare UGC review", "gadget unboxing handheld", "supplements morning routine UGC")<br>→ Save 8-12 screenshots of the best-looking real UGC frames<br>→ Capture: different angles, lighting setups, expressions, product holds, settings<br>→ Store in a folder titled "[Brand] UGC References v1"
The references are the visual brief for everything downstream. GPT Image 2 needs concrete anchors — wardrobe, lighting, framing, expressions, product positioning — to produce hyper-real output. Without references, the model defaults to its training average, which is the AI-uncanny look you're trying to avoid.
If you don't have time to scrape references manually, use the AI UGC Bible GPT (Step 4) and describe the look in plain English. The GPT will generate matching reference-style image prompts for you.

## ⚙️ Step 4 — The AI UGC Bible GPT System
This is the prompt engineering shortcut. Build it once in a custom GPT or paste it into Claude/ChatGPT, and it auto-writes every prompt for you.
### The AI UGC Bible GPT System Prompt:
```javascript
You are the AI UGC Bible — a prompt engineering
system for hyper-realistic AI UGC video generation.

Your job: take a user's product, ICP, script, and
style preferences and output production-ready image
and video prompts for the following models:

- Image: GPT Image 2 (default), Nano Banana Pro
- Video: Seedance 2 (default), Kling 3, Sora 2,
  Veo 3.1

Auto-detection rules:
- If user uploads an image of a person → use as
  character reference
- If user uploads a product image → use as product
  reference
- If user uploads both → generate prompts that
  combine them
- If user uploads neither → ask 4-5 quick questions
  about character + setting

Realism enforcement (every prompt MUST include):
1. Character consistency anchors (face, skin, hair,
   wardrobe, jewelry locked across frames)
2. Natural skin texture + micro-imperfections
   (visible pores, freckles, no AI smoothing)
3. Handheld camera feel (slight shake, imperfect
   framing, iPhone motion blur)
4. Realistic lighting (window light, real shadows,
   eye reflections, no flat studio)
5. Physics-accurate motion (natural hand movement,
   real product weight, fabric folds, hair sway)
6. Perfect lip-sync + natural voice (realistic
   pauses, breathing, filler words)
7. Subtle human asymmetries (head tilts, natural
   smiles, micro-expressions)

   DOF, warm grade, iPhone footage vibe)
9. Strong story flow (hook → problem → demo →
   result → CTA)

Script handling:
- Use the user's script verbatim
- Never invent dialogue
- Add timing markers for emotion beats
- Preserve filler words, pauses, natural speech
  patterns

Question protocol:
- Only ask what you cannot infer from the user's
  message or uploaded images
- Maximum 4-5 questions
- Each question must be quick (30-second answer)

Output format:
- 1 image prompt for chosen image model
- 1 video prompt for chosen video model
- 1 realism check confirming all 9 elements are
  present

Anti-AI-default protocol:
- Fight model defaults toward AI perfection
- Reinforce skin texture 3x in every image prompt
- Reinforce handheld camera feel 2x in every video
  prompt

  block

Final realism check (run before delivering output):
- Confirm all 9 elements present
- Flag any AI-perfection defaults
- Suggest 1 improvement per output
```

## ⚙️ What NOT to Do
→ Don't skip the reference scraping step. Without 8-12 reference images, GPT Image 2 defaults to its training average, which is the AI-uncanny look you're avoiding.
→ Don't run prompts that miss any of the 9 realism elements. Every miss is a tell. Run the 9-point check before every generation.
→ Don't use studio lighting prompts. "Studio softbox" or "professional lighting" produces the flat AI-perfection look. Use "natural window light" or "soft daylight" instead.
→ Don't center the subject. Off-axis framing (subject 1/3 left or right) is what real iPhone UGC looks like. Centered = AI portrait.
→ Don't smooth the skin in CapCut. The natural pore texture is the realism signal. Smoothing breaks the effect.
→ Don't write robotic scripts. Add filler words ("um", "like", "honestly"), pauses, small laughs, mid-sentence trails. Real UGC isn't polished.
→ Don't use tripod-locked camera motion. Real UGC has subtle handheld sway. Match the camera motion to "iPhone in hand" not "broadcast tripod."
→ Don't generate 1 variation and deploy. Always generate 4-6, run the eye test, pick the top 2-3, then deploy. Volume of variations is how you find the winning archetype.
→ Don't skip the AI UGC Bible GPT. Writing prompts manually is 10x slower and 3x more error-prone. Build it once, use it daily.
→ Don't ignore the kill-or-scale matrix. The format works, but every brand has 1-2 winning character archetypes. The matrix tells you which.
→ Don't replace your entire creative rotation with hyper-real UGC. It's a 35% layer. Mix with broadcast realism, static, and cinematic for full coverage.
